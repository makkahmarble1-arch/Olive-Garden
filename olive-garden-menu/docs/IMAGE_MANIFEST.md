## How to add or replace a photo

1. Put the original in `image-staging/<category>/`.
2. Optimize to 600 × 450 WebP (same steps as above) and save it under the file name listed here.
3. Set `image` (src, alt, width 600, height 450) on the product in `content/menu/products.ts` and clear `imageIssue`.
4. Update this manifest.

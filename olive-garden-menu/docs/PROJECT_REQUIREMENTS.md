# Project Requirements

## 1. Overview

| Item | Value |
|---|---|
| Site name | Olive Garden Menu & Prices (independent; branding may be refined later) |
| Domain | Not decided; never hardcoded (env var `NEXT_PUBLIC_SITE_URL`) |
| Type | Independent, informational food blog |
| Audience | Diners in the United States |
| Language | English (all public-facing content) |
| Owner experience | Complete beginner; built with Cursor + Claude Code |
| Hosting | Vercel (deployed from GitHub) |

**Goal:** Help US diners quickly find Olive Garden menu items, typical prices,
and calorie information, plus helpful guides (deals, ordering tips, etc.),
on a fast, accessible, mobile-first website.

**This is NOT an official Olive Garden website.** The site is not affiliated
with, endorsed by, or sponsored by Olive Garden or Darden Restaurants, Inc.
This must be stated clearly on the site (footer on every page + Disclaimer page).

- Project folder: `olive-garden-menu/` (inside the git repo at `Olive Garden/`)

  older versions; docs are bundled in `node_modules/next/dist/docs/`.
- No custom components, data, or content exist yet.

## 3. Functional requirements

### Pages
| Page | Purpose |
|---|---|
| Homepage | Overview of the full menu with price ranges, links to every category, latest guides |
| Menu category pages | One page per category with a prices + calories table |
| Blog index | List of all articles |
| Blog articles | Informational guides with TOC, FAQ, related articles |
| About | Who runs the site, how prices are collected and verified |
| Contact | How to report wrong prices (email shown as text) |
| Disclaimer | Non-affiliation, trademark notice, price accuracy notice |
| Privacy Policy | Required before adding analytics or ads |
| 404 page | Helpful links back to menu categories |

### Page features
- Responsive header with mobile menu
- Footer with category links, legal links, and non-affiliation notice
- Breadcrumb navigation on every page except the homepage
- Table of contents on long pages (blog articles, long category pages)
- FAQ section (visible on the page, optional per page)
- Related articles / related categories
- Internal links between menu pages and guides
- Prices and calories tables (accessible HTML `<table>`)
- "Prices last checked" date and location-variance note near every price table

### Technical requirements
- SEO metadata on every page (title, description, canonical, Open Graph)
- `sitemap.xml` and `robots.txt` generated by Next.js
- Structured data (JSON-LD) where appropriate (see `SEO_ARCHITECTURE.md`)
- Optimized images with `next/image`
- Clean, lowercase, hyphenated URLs
- Static generation for all pages (fast loading, cheap hosting)
- Accessibility: WCAG 2.2 AA target
- Mobile-first responsive design

## 4. Content accuracy rules (critical)

1. **Never invent prices or nutrition facts.** If a value is not verified,
   store it as `null` and show "Not verified yet" on the site.
2. Every menu item records: `price`, `calories`, `status`
   (`"verified"` or `"needs-verification"`), and `source` / `lastChecked`.
3. Prices vary by location and change over time. Show this note near every
   price table.
4. Calories should come from Olive Garden's official published nutrition
   information. Record the source and date.
5. Placeholder/sample data must be clearly marked in code
   (`status: "needs-verification"`) and must never be shown as fact.
6. No fake reviews, ratings, or testimonials.

## 5. Brand and legal rules

- Do not use Olive Garden's logo, official photos, or brand styling.
- Use only images we own, license, or create.
- Use the brand name only to describe the restaurant (nominative use),
  never to suggest affiliation.
- Do not use `Restaurant`, `Menu`, `Product`/`Offer`, or rating structured
  data that suggests we are the restaurant or sell its food.

## 6. Out of scope (for now)

- User accounts, comments, or a database
- A CMS dashboard (content lives in TypeScript files in the repo)
- Online ordering, maps, or store locators
- Multiple languages
- Paid ads (can be added later, needs Privacy Policy update)

## 7. Owner decisions and pending information

See "Owner decisions and pending information" in `DEVELOPMENT_ROADMAP.md`.
Because the site name contains the restaurant's name, the non-affiliation
disclaimer is mandatory in the footer of every page, on the Disclaimer page,
and the About page.

## 3. Semantic cluster [Inferred]
- **Drink types:** non-alcoholic (lemonades, limonatas, iced teas, soda, coffee), wine and beer to go, dine-in Italian-inspired cocktails (official specials page, no online prices), sangria, margaritas.
- **Other terms:** refills, drink sizes (single, 2-liter, gallon), drink calories.

## 4. Search intent
- **Primary:** informational and commercial. Visitors want an overview of *all* drink types with prices.
- **Secondary:** split by alcohol vs non-alcohol; cocktails; to-go drinks.
- **Format:** an overview hub. Each drink type gets a short table or summary and a link to the dedicated page.
